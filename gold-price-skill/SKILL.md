# 黄金价格实时查询与分析

## 功能概述

本技能提供全面的黄金价格查询和分析服务，包括：
1. **实时价格查询**：获取国际金价（美元/盎司）和国内金价（人民币/克）
2. **技术面分析**：基于价格走势、涨跌幅、技术指标进行分析
3. **投资建议**：根据当前行情给出观望、买入或卖出建议
4. **新闻事件分析**：查询近期影响黄金市场的重要事件

## 使用方法

### 快速查询黄金价格

```bash
python scripts/gold_price.py
```

### 带详细分析的完整报告

```bash
python scripts/gold_price.py --full-analysis
```

### 仅查询新闻事件

```bash
python scripts/gold_price.py --news-only
```

## 输出内容说明

### 1. 实时价格信息
- **国际金价**：美元/盎司（伦敦金、COMEX黄金期货）
- **国内金价**：人民币/克（上海金交所AU9999、黄金T+D）
- **涨跌幅**：当日涨跌金额和百分比
- **关键价位**：开盘价、最高价、最低价、收盘价

### 2. 技术面分析
- **趋势判断**：上涨/下跌/震荡
- **技术指标**：MACD、KDJ、RSI、SAR、CCI等信号
- **支撑阻力位**：关键技术水平
- **波动率分析**：近期价格波动情况

### 3. 投资建议
基于以下因素综合判断：
- 当前价格相对历史位置
- 技术面信号
- 市场情绪
- 近期新闻事件影响

投资建议等级：
- **强烈买入**：多重利好，价格处于低位
- **买入**：趋势向好，可逢低布局
- **观望**：方向不明，等待 clearer signal
- **卖出**：趋势转弱，考虑获利了结
- **强烈卖出**：多重利空，价格处于高位

### 4. 新闻事件分析
查询并分析近期影响黄金价格的事件：
- 美联储货币政策（利率决议、鲍威尔讲话）
- 地缘政治风险（中东局势、俄乌冲突等）
- 全球贸易局势（关税政策、贸易摩擦）
- 美元走势（美元指数、美债收益率）
- 央行购金动态（中国、印度等央行增持）

## 数据来源

- **金投网** (https://quote.cngold.org/) - 主要数据来源
- **新浪财经** - 补充价格数据
- **世界黄金协会** - 行业报告和央行购金数据

## 注意事项

1. 价格数据为实时行情，可能存在短暂延迟
2. 分析建议仅供参考，不构成投资建议
3. 黄金市场波动较大，投资需谨慎
4. 建议结合多种信息源进行决策

本技能使用 Python 编写，依赖以下库：
- `requests` - 网页请求
- `beautifulsoup4` - HTML解析
- `json` - 数据处理

无需额外配置，直接运行即可。
